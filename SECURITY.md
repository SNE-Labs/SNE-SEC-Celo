# Security policy

Please report vulnerabilities through this repository's private GitHub Security Advisory flow.
Do not include private keys, bearer tokens, reusable payment authorizations, cookies, customer
evidence, or other credentials in an issue, discussion, test fixture, or public proof.

The reference provider is authorized only for low-impact observation of public HTTP(S) origins.
Reports requesting exploit payloads, credential attacks, brute force, port scanning, directory or
subdomain enumeration, or authentication bypass are outside the product's authority.
